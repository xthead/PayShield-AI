🛡️ PayShield AI — Protect Before You Pay

An intelligent payment-safety concept designed to help users identify suspicious payment requests before sending money.

🚨 The Problem

Online payment scams often use fake payment requests, impersonation, suspicious links, and urgent messages to trick people into sending money.

Many users struggle to identify these warning signs before making a payment.

💡 Our Solution

PayShield AI is a payment-safety prototype that analyzes suspicious messages and URLs, highlights potential scam indicators, and explains why a payment request may be risky.

Our goal is simple:

Protect people before they pay.

✨ Key Features

- 🔍 Message Analysis: Scan suspicious payment messages.
- 🌐 URL Analysis: Identify potentially suspicious links and lookalike domains.
- ⚠️ Risk Assessment: Generate a risk score based on detected warning signs.
- 🧠 Explainable Detection: Show users the reasons behind a risk assessment.
- 🔒 Risk-Aware Checkout Concept: Demonstrate how a risky payment could be stopped before checkout.
- 📊 Session Dashboard: Display activity from the current session.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Rule-based message and URL analysis
- PayPal Sandbox integration concept

🚀 How to Run the Project

1. Clone or download this repository.
2. Locate the main HTML file.
3. Open the HTML file in a modern web browser.
4. Enter a sample suspicious message or URL.
5. Click the scan button.
6. Review the risk score and explanation.

🧪 Current Implementation

The current prototype uses transparent, rule-based heuristics and pattern matching to identify suspicious message and URL characteristics.

Important: This version is not yet a trained machine-learning fraud detection model. PayPal checkout requires Sandbox configuration and is not enabled for real transactions.

This project is an independent prototype and is not an official PayPal product or security service.

🔮 Future Improvements

- Improve detection using representative scam and legitimate-message datasets.
